# Credits

F1Zone is an unofficial study project and a demo shop that sells nothing. It is not connected with Formula 1, the FIA or any team, and their trademarks belong to their owners. The cars, liveries, helmets and circuits on this site are invented. They do not depict a real team, driver, sponsor or venue.

## Artwork made for this project

These files were generated by the code in `art/source/` and contain no third-party models, photographs, textures or lighting maps. Author: Dawid Olko. Licence: MIT, the same as the repository ([LICENSE](LICENSE)).

| Asset | Files | How it was made |
| --- | --- | --- |
| Hero car | `img/hero/` | Invented open-wheel car modelled in code, then path traced under procedural softboxes |
| Livery posters | `img/posters/*-livery*` | The same car in six invented colour schemes |
| Helmet posters | `img/posters/*-helmet*` | Invented helmet modelled in code with eight painted designs |
| Circuit posters | `img/posters/*-circuit*` | Three invented circuit layouts, not based on real venues |
| Collection and offer images | `img/collections/` | Crops and close views of the renders above |
| Wordmark, favicon | `img/brand/`, `logo.png` | Letterforms drawn by hand as vector paths |
| Service icons | `img/icons/` | Drawn by hand as vector paths |
| Social image, README images | `img/og-image.jpg`, `docs/readme/` | Built from the renders above and live screenshots of this site |
